CONTEXT: Looking for any mechanism by which real current/field dynamics under plain step() could generate a genuine Ampère (curl-carrying) magnetic field, tested via a long thin cylinder with two fixed-u point sources on axis (a genuine directional current, exp/2026/09/05/17_44_directional_current_ampere/probe_directional_current_ampere.py), meant to have a nonzero classical target B_phi(rho)=I_enc(rho)/(2*pi*rho) to check against.

WHAT FAILED: Confirmed a real, extended, growing directional current (I crossing z=0 grew to +129.8 by step 20000, still climbing; I_enc(rho) grows smoothly from 4.6 at rho=1 to 86.5 at rho=5.3 — a genuine axisymmetric current, not a point-source spike). But B_azimuthal (the actual Ampère-circulation component, curl(phi) projected tangentially around the current axis) = 1e-15 to 1e-16 in every well-resolved interior bin — floating-point noise, despite substantial real I_enc at every radius. Only the outermost, boundary-adjacent bin showed anything nonzero (0.137, a boundary artifact). B_z rms=9e-4 and B_radial(perp) rms=0.04 are both nonzero, so it's specifically the azimuthal (Ampère) component that's exactly null.

ROOT CAUSE, later proven exactly (not just observed): E_full := -grad(u) - dphi/dt was already confirmed identically zero (rms~1e-18) as an algebraic consequence of the update rule itself (dphi[i,k]/dt = -sigma_face*W_k*(u_nb-u_i) IS a per-face copy of -grad(u) by construction). Taking curl of both sides: curl(dphi/dt) = curl(-grad(u)) = 0 identically, so d(curl phi)/dt = dB/dt = 0 under plain step(), for ANY field, ANY current, ANY IC. B=curl(phi) is a provably frozen invariant under plain step() — it cannot be sourced by real dynamics at all, no matter how directional or well-confined the current is. Phi driven by plain step() from a pinned-u source behaves like a gradient of the scalar potential u (Coulomb-like), and a gradient field is curl-free by construction — the already-validated curl(phi)=B reconstruction only produces nonzero classical fields in the static tests (test_curl.py/test_curl_loop.py) because phi was HAND-SET directly to a genuine non-gradient vector-potential shape; real dynamics from a scalar-potential-like source never seeds that structure on its own.

LESSON: No probe built on plain step() — regardless of IC, current geometry, or resolution — can ever produce a genuine dynamically-sourced B. Don't build more "does a real current source a field" tests under plain step(); the identity guarantees a null before the run even starts (if phi=0 at t=0, B=0 forever). Only a hand-set IC that already has nonzero curl(phi) baked in (test_curl.py/test_curl_loop.py-style, or a winding's own initial spin structure) can show a nonzero B, and even those can never gain or lose curl through plain step() afterward — frozen at whatever the IC started with. Any real Ampère/Lorentz physics needs an explicit new coupling term added to the equations (not yet derived) — this is the concrete missing piece, not a resolution or geometry problem. (Consistent with, and explains, the earlier point-source B=0 null and the photon-staircase null — see photon-staircase-no-direction-dependence.txt.)

CORRECTION (2026-09-06, night): the "for ANY field, ANY current, ANY IC" claim above is an OVERCLAIM — it silently assumed uniform sigma (this probe, and every other Ampère-hunt probe to date, used lam=0/vacuum throughout). The actual algebraic step was "curl(dphi/dt) = curl(-sigma_face*grad(u)) = curl(-grad(u)) = 0" — valid ONLY when sigma_face is a spatially-uniform constant (so it factors out of the discrete curl exactly, same as a global constant multiplying any curl-free field); with sigma varying (nonzero, spatially asymmetric lam), sigma_face*grad(u) is NOT expressible as a scalar's discrete gradient in general, and its curl is NOT zero. Confirmed directly and cleanly: two fixed-u point sources (real asymmetric current) + an off-axis lam bump (lam_peak=3.0, breaking grad(sigma)-vs-grad(u) alignment), plain step(), 500 steps — control (lam=0): |B|_rms=1.7e-16 (noise, reproduces the null above exactly). Test (lam≠0): |B|_rms=1.68e-2, ~8.9% of phi_rms -- a real, substantial, non-noise effect, from plain step() alone, no new term. Scaling check (lam_peak=3.0/0.3/0.03/0.003): |B|_rms/phi_rms scales cleanly ~linearly down to 1.2e-4 at the smallest lam — confirms this is a genuine, well-behaved perturbative effect (not a numerical artifact), and that it is the SAME mechanism already identified and retracted-as-"not the magnetism mechanism" in `grad-sigma-cross-grad-u-not-magnetism-mechanism.txt` (there derived analytically as a circulation-generation formula and found "real but numerically inaccessible at any real scale") — now independently reconfirmed via direct dynamical simulation rather than the analytic formula. So: the frozen-B identity correctly describes DST in vacuum/uniform-sigma regions (still true, still the reason every prior photon/traveling-wave test saw exactly zero B) but is FALSE in general wherever sigma varies — a real, if weak-at-realistic-scale, native curl-sourcing mechanism already exists in DST's own equations, requiring no new field or term. Does not resolve the "genuine leapfrogging EM wave" question (this mechanism is real but too weak at realistic lam to be the dominant magnetism source, consistent with the standing understanding that real DST magnetism comes from motion/circulation of lam, not this gradient-cross term) but corrects the scope of this file's own central claim.
