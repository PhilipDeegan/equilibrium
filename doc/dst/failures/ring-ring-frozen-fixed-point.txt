CONTEXT: Tested two coaxial frozen toroidal-ring current loops (same-sense vs opposite-sense circulation, via find_toroidal_ring+set_flux_loop) as a lightweight proxy for classical magnetic dipole-dipole interaction, intended as a dynamically-reachable "pretend proton" test (exp/2026/09/05/17_44_directional_current_ampere/probe_ring_dipole_interaction.py).

WHAT FAILED: The static energy comparison (0.5*sum(phi^2)) is algebraically trivial because the two rings share no edges, so the cross term is exactly 0 by construction, not physics. The dynamic follow-up showed the entire system is an exact static fixed point from t=0 — H, u_rms, |B| at the midpoint were bit-identical across the full 2000-step run in both same-sense and opposite-sense configurations. No ring-ring interaction was testable this way at all.

ROOT CAUSE: Checked directly — a closed loop's own two nonzero phi entries at each ring cell (same sq-face weight, opposite sign) cancel exactly, so du/dt=0 even AT the ring cells. With u≡0 everywhere, dphi/dt=-∇u=0 everywhere else too. Nothing can ever propagate out from a frozen closed loop under plain step() — this is a general fact about hand-set closed-loop ICs, not specific to this geometry.

LESSON: Don't build ring-ring (or any closed-loop-pair) interaction probes expecting dynamics under plain step() — a closed loop with only the minimal two-phi-per-cell construction is a guaranteed static fixed point and can never radiate or interact with anything else. Any interaction test needs either a genuinely open/unclosed structure or an explicit sourcing mechanism (still missing — see b-field-frozen-under-plain-step.txt) to make one loop's field move at all.
