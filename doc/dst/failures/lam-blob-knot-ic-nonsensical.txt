ROOT CAUSE: found while explaining a translation result to Philip. The IC set lam to a hand-picked profile while phi=0 everywhere. Per the canonical lam definition ([[project_dst_lam_definition]]: lam = "mc²-worth of phi being geostationarily locked out", a bookkeeping trace of REAL nearby trapped phi), a lam value with zero phi anywhere near it is not a weak/edge-case proton — it is a state step_lam (the actual phi->lam mechanism, Δlam ∝ σ·lam·Σ W_k·φ_ik, exactly zero whenever phi is zero) could never have produced. The zero-circulation property was chosen deliberately as a contrast to the electron, but that same property means the IC was never reachable by DST's own dynamics — not just untested or confounded, but structurally impossible under step_lam.

LESSON: never construct an IC by hand-setting lam without a co-located, dynamically-consistent phi field. Before building any lam-only or lam-dominant IC, check it could actually arise from step_lam's own update rule (nonzero phi somewhere in the neighborhood).
